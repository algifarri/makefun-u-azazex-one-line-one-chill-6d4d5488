One sentence of horror for make.fun's "One Line, One Chill" bounty: a dead narrator, an impossible finding. The coroner found sand in the lungs of someone who never saw the sea — the dread is in what the line withholds.

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader's container). Deterministic: every run writes exactly the same 66 characters, one sentence, one line, no trailing newline.

## Run it

```sh
python3 main.py
```
